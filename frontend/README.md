# Z-Grow AI Banking Solutions - Frontend

Modern, high-performance corporate banking frontend powered by **Next.js 16**, **React 19**, and **Tailwind CSS v4**.

## 🚀 Portals & Routes

* **`/`** - Main Portal Switcher with Zgrow AI Banking Solutions branding.
* **`/client`** - Corporate Client Onboarding & Application Submission (Passports, Trade Licenses, Audited Financials).
* **`/staff/applications`** - Staff Dashboard with queue management for Business Account Opening and Commercial Loan Review.
* **`/staff/knowledge`** - Operations Knowledge Base & Grounded "Ask AI" Assistant with interactive document citations.

## ⚙️ Environment Variables

Set the following variable in `.env.local` or your Vercel Project Settings:

```env
NEXT_PUBLIC_API_URL=https://ai-banking-backend-4i9b.onrender.com
```
